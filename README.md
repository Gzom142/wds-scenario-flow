# wds-scenario-flow

『ワールドダイスター 夢のステラリウム』のストーリーを、劇団ごとのメイン章と関連イベントとして可視化する個人用ビューアです。

> このサイトは非公式の個人制作・二次創作です。『ワールドダイスター』公式および関係各社とは関係ありません。

- [『ワールドダイスター』二次創作ガイドライン](https://world-dai-star.com/news/1947)
- [『ワールドダイスター 夢のステラリウム』利用規約](https://shop.wds-stellarium.com/Terms)

## 起動

```bash
npm install
npm run dev
```

Windowsでは、初回のみ `setup.cmd` を実行して依存関係をインストールし、以降は `start.cmd` で開発サーバーを起動できます。

## データ編集

- `src/data/characters.yml`: キャラクター、所属劇団、表示色
- `src/data/stories.yml`: 画面に表示するストーリー、劇団、接続（手動で意味付けするデータ）
- `src/data/story-index.json`: 初期移行時に作成した、ID・タイトル・章・話数・イベント日付だけの索引

`storyData.js` は読み込み時に、重複 IDと未定義キャラクター／ストーリーへの参照を検出します。

### データの取り扱い

- 今後の追加・修正は、公式サイト、公式SNS、または通常のゲームプレイで確認できる事実を手動で整理します。
- ゲームプログラムの解析、抽出されたリソース、権利・由来を確認できないデータは更新元として使用しません。
- 台詞、音声、画像、背景、シナリオ本文など、コンテンツ本体は収録しません。
- 公開中イベントの核心に触れる情報は掲載せず、公式ガイドラインと利用規約の更新に応じて運用を見直します。
- タイトル、章番号、公開日、推奨視聴順は公式告知を優先します。

### 公式告知の登録

`stories.yml` の `overrides` に `tweetUrl` を設定すると、詳細パネルに公式X投稿を埋め込みます。URLは `https://x.com/<アカウント>/status/<投稿ID>` のような投稿本体のURLを指定してください。`tweetUrl` が未登録で `officialUrl` がある場合は、公式サイトへのリンクを表示します。

個人ユーザーによるストーリー概要・あらすじは掲載せず、公式告知を案内欄として使用します。

公式投稿は引用元が分かる埋め込みまたはリンクとして表示し、画像・本文をリポジトリへ転載しません。

## GitHub Pages

リポジトリの **Settings → Pages → Build and deployment** で **GitHub Actions** を選択すると、`main` への push 時に `.github/workflows/deploy.yml` がビルド・公開します。
